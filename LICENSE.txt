External dependencies

NV-UV needs MSI Afterburner to work. NV-UV does not include or
distribute MSI Afterburner — please install it separately from
msi.com and follow its own license terms.

NV-UV reads from and writes to MSI Afterburner configuration files
and the MAHM shared memory interface. If MSI changes how Afterburner
works in the future, NV-UV may stop working — there's no way I can
guarantee long-term compatibility with software I don't control.
